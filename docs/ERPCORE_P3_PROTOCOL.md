## 最大的改动：真实数据没有已知真值，主指标换了

之前的主指标是“估计值离已知的注入目标有多远”（MSE）。真实数据里没有这个已知目标，所以主指标改成**测量精度**：同一个人的 P3 差波幅度，用试次重采样算出来的标准误越小，说明这条管线测得越稳。精度是 PipeCompare 本来就在优化的东西（SME），这个改法没有偷换概念，只是把“离真值多远”换成了“自己测得有多稳”。

- P3 差波：目标刺激减非目标刺激，Pz 电极，300–600 毫秒平均幅度。窗口和电极与 PR51 的口径完全一致（ERP CORE 论文 Table 2 推荐窗口就是 300–600 ms，Pz）。
- 精度：每人对试次做 1000 次 bootstrap 重采样，算 P3 差波幅度的标准误（SE）。三条臂（原版、最简固定、常用固定 ICA）各自算，配对比较。重采样只用保存下来的逐试次分数和权重算，由收集器独立重算，不用工具自己报的 SME，也不依赖 MATLAB 的结果。
- 一致性（次要指标，不设门，只报告）：原版测出的 P3 幅度，与按 ERP CORE 论文发表的流程算出的幅度差多少。如果原版系统性地偏大或偏小，那就是偏差信号。

- 参考：工具的三条臂一律用**平均参考**，与 PR51 试点相同。草稿写的“离线参考取 P9/P10 平均”改在这里：`pop_pipecompare` 的 `reference` 参数只有 `asis` 和 `average` 两档，没有按通道列表参考的功能，所以工具走不通 P9/P10 参考。发表流程的 P9/P10 参考幅度在 MATLAB 里另外算（次要指标），不走工具。
- 事件重标记：刺激事件的两位码里，十位是本块的目标字母（1=A…5=E），个位是呈现的字母；十位等于个位时（11、22、33、44、55）是目标，其余 20 个码是非目标。`pop_pipecompare` 的 `events` 参数每个条件只能对应一种事件码，表达不了“目标 = 5 个码、非目标 = 20 个码”，所以在取数那一步就把事件重标记：所有目标码改成 `11`，所有非目标码改成 `31`，正确性/反应时筛过之后再去掉反应事件。这样原版跑的是和 PR51 试点完全相同的代码路径。原始码、正确性、反应时都保存在 `input.mat` 的试次表和 `source.json` 里，重标记完全可查。

## 跑之前写死的通过标准

主指标：每人 P3 差波幅度的 bootstrap 标准误（1000 次试次重采样，种子 520004 + 受试者编号）。20 人的配对差取均值，整人一起重采样 10000 次，种子 510004，95% 区间（顺序统计量 `ceil((B+1)*q)`，截到 [1, B]）。

同时满足以下全部，才算“原版在真实任务上更准”成立：

- 20/20 对子完整有效；来源、协议、对照、复现无一处对不上。
- 精度：原版平均标准误低于最简方法，且 95% 区间整个在 0 以下；同时低于常用 ICA 方法，且 95% 区间整个在 0 以下。
- 校准：工具报告的标准误与 bootstrap 标准误的比值（RMS 之比），95% 区间整个落在 [0.8, 1.2] 内。上一批半合成数据上是 1.54，属于不合格。
- 稳定性：换 ICA 起点后推荐不变的人数 ≥18/20。
- 对照充足：每条件有效未标记对照 ≥5（有效数 = (权重和)² / 权重平方和）；不达标的对子单独列出、不悄悄删掉；超过 2 个对子不达标，本批对主结论算不完整。
- 试次下限：每人排除后目标试次 ≥15、非目标试次 ≥60，否则该对子算不完整，不换人、不补人。
- 个别退步：原版标准误比最简方法差超过 20% 的人数 ≤2 人（超过 20% 且超出 0.05 µV 的绝对 allowance 才算退步）。

结论分四档，跑之前就定好：

- 成立：上面全部满足。
- 部分成立：只赢了最简方法，没赢常用 ICA 方法；或校准、稳定性有一项不满足。只写实际满足的部分，不升格。
- 未成立：两个配对区间都没整个低于 0。保留不利证据，不删数据。
- 不完整：有对子缺失、失败或不一致。不换人、不补人、不拿老数据凑数。

以上阈值是本轮预先定的筛选规则，不是生理或临床标准，跑完不改。
